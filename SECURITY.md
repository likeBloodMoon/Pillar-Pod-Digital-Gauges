# Security Policy

## Supported versions

Only the [latest release](https://github.com/likeBloodMoon/Pillar-Pod-Digital-Gauges/releases/latest) gets fixes. If you're on an older version, update first and check whether the problem is still there.

## What counts as a security issue

Pillar Pod Digital Gauges is a BeamNG.drive mod. It runs Lua inside the game and shows its screens as HTML pages in the game. Please report it privately if you find a way for the mod to:

- run code or game commands it shouldn't
- read, change or delete files outside the game's own mod data
- be abused by another mod, a map or a multiplayer server to do either of the above

Bugs, crashes, wrong readings and gauges in the wrong place aren't security issues. Please open a normal [issue](https://github.com/likeBloodMoon/Pillar-Pod-Digital-Gauges/issues) for those.

## How to report

Use **[Report a vulnerability](https://github.com/likeBloodMoon/Pillar-Pod-Digital-Gauges/security/advisories/new)** on GitHub, so the details stay private until there's a fix. Please don't post security problems in public issues or on the BeamNG forum.

Include the mod version, the game version, and steps to reproduce if you can.

This is a hobby project maintained by one person, so I can't promise a fixed response time. I'll aim to reply within a week. If the report is confirmed, I'll fix it in a new release and credit you in the release notes, unless you'd rather stay anonymous.
